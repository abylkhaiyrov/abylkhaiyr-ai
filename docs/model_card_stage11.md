# Abylkhaiyr AI Tiny SFT-v3.1

**Статус — экспериментальный.** Выбранный checkpoint — `checkpoints/tiny_v31_sft_stage11/step-00000120`. Производственного checkpoint нет.

Модель — decoder-only Transformer с 15 735 168 параметрами, словарём 8192 токена и контекстом 512 токенов. Обучение начато с локального pretrained checkpoint v2 на 6000 шагах. SFT выполнен на группах v3.1 с небольшим replay обычного корпуса v2 из обучающих выборок EN/RU/KK. Дополнительное обучение предпочтениям не запускалось.

## Что показала оценка

- На одинаковом отложенном корпусе v2 тестовая perplexity составила **22,16**. У pretrained checkpoint она составляла **19,66**, у SFT-v1 — **46,55**.
- Пройдено **17 из 53** диалоговых примеров. Доля пройденных случаев составила **36% EN, 25% RU и 37,5% KK**. Языковые подгруппы малы, поэтому эти значения не описывают весь язык.
- В математическом наборе модель самостоятельно решила **2 из 60** задач. Режим с инструментами решил **51 из 60**. Это результат всей системы, включая решатели и проверку.
- Код не прошёл локальные проверки ни в `pass@1`, ни в `pass@4`. На локальном фактическом наборе точность составила **0%**. На отдельном логическом наборе самостоятельная точность тоже составила **0%**.
- Модель прошла критерий сохранения языковых способностей, но не достигла порога диалогового качества **50%**, необходимого для DPO и production.

## Использование и ограничения

Подходит для локальных экспериментов с обучением, диалогом и проверяемыми задачами с инструментами. Не полагайтесь на модель в задачах, требующих точных фактов, надёжного программного кода или самостоятельных длинных рассуждений. При 512 токенах контекста часть старых сообщений может не войти в запрос. Сами веса не дают доступа к интернету и не сохраняют память между запусками. Проверяйте результат инструментов на задачах вне их поддерживаемых форматов.
