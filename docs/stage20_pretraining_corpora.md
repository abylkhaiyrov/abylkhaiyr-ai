# Этап 20. Корпуса A, B и B с replay v2 на LR 5e-5

Регистрация: [stage20_preregistration.md](stage20_preregistration.md). Аудит отказов SFT и план SFT A/B/C описаны там же; SFT не запускался.

## Что выполнено

Серия запущена после одобренного снижения запаса RAM до 0,25 ГиБ. Завершены B-1 и R-1 (305 шагов, 4 997 120 токенов каждый); A-1 взят из этапа 19 (L1, идентичные данные, init, LR, seed и расписание). Серия остановилась на абсолютном сроке 65 минут: машина простаивала около 50 минут (временные метки лога 23:44 → 00:18), и A-2 не дошёл до шага 305. Срок не продлевался, прогоны не повторялись. Остальные задания (A-2, B-2, R-2, A-3, B-3, R-3) не выполнены.

По правилу регистрации seed учитывается только при трёх завершённых ветках, поэтому в сравнении один seed (1). Интервалы отражают только вариацию по семействам заданий, но не вариацию обучения; выводы о корпусах предварительные.

## Проверка гипотез

- **HB1 (B − A ≥ +3 п.п. по P1, нижняя граница выше 0): не подтверждена.** Разность +0,52 п.п., интервал [−1,0; +2,2].
- **HB2 (R ниже B по PPL v2 на 0,01 и более по среднему трёх seed): не подтверждена по правилу регистрации.** Для seed 1 разница 1,0244 − 1,0142 = 0,0102, то есть на пороге; трёх seed нет, поэтому это описательный результат.
- **HB3 (R − A ≥ −1 п.п. по P1): точечно выполнена** (−0,09), но нижняя граница интервала −1,7; без повторных seed не подтверждена.
- **HB4 (отношения PPL не выше 1,03): выполнена** у всех трёх веток на v2 val/test и s18 val (максимум 1,025).
- **HB5 (падение по языку не более 5 п.п.): выполнена описательно**, максимум −4,4 п.п. (KK у R), у R на казахском самый большой регресс.

## Решения

- Корпус B не признан перспективным (HB1 не подтверждена). Replay v2 уменьшает регресс PPL на v2 примерно до уровня A, но его пользу для задач подтвердить нельзя: нужны минимум три seed.
- Гейт для SFT A/B/C не открыт: условия HB1 и HB2 не подтверждены. SFT A/B/C не запускался и остаётся зарегистрированным планом.
- Дозапуск seeds 2 и 3 возможен только отдельной регистрацией с новым бюджетом и защитой от простоя машины (например, срок по времени работы процессов, а не по настенным часам).
- Production остаётся `null`. Studio не менялся.
