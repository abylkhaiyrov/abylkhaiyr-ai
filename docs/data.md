# Данные

## Принципы
- Только открытые данные, написанные людьми, с разрешающими лицензиями. Данные закрытых коммерческих моделей не используются.
- Исключены источники, сгенерированные LLM: TinyStories (GPT-3.5/4), CodeAlpaca (text-davinci-003), Magicoder (OpenAI),
  HH-RLHF (ответы закрытой модели). Preference-пары строятся из OpenAssistant (ответы людей, ранги людей).
- Для кода применяется фильтр по полю лицензии файла (`allowed_licenses`: MIT, Apache-2.0, BSD, ISC, Unlicense, CC0).
- Деконтаминация: документы с 8-граммным пересечением с тестовыми наборами (GSM8K test, eval-задачи кода, факты,
  инструкции) удаляются из корпуса до разбиения.
- Дедупликация (точная и MinHash) выполняется до разбиения на train/validation/test, раздельно для корпуса и SFT.

## Версии
`configs/data_v2.yaml` создаёт `data/v2` с `version: v2`; версия пишется в `manifest.json`. Каталог `data/processed` (v1)
сохранён неизменным как база для воспроизведения первой точки сравнения.

## Группы и сбалансированное семплирование
Каждый источник имеет `group` (ru, kk, en, math, code). Токены хранятся в `tokens/{split}.{group}.bin`. Параметр
`train.mixture` задаёт веса групп; `MixtureLoader` выбирает группу детерминированно по счётчику, поэтому resume точный.

## SFT
Группы `chat`, `math`, `code` в `sft_groups/`. Математика идёт в порядке curriculum (уровни 1-5, сложность растёт),
остальное перемешивается. Источники: Dolly, Aya, OpenAssistant (en, ru), GSM8K train, синтетическая математика
(SymPy), синтетические задачи по коду (проверены запуском в песочнице), примеры признания незнания (en, ru, kk).

## Бенчмарки (не попадают в обучение)
- `data/benchmarks/math_bench.jsonl`: 150 задач, seed 777, ключи вопросов исключены из обучающей генерации.
- GSM8K test, задачи по коду (функции, которых нет среди обучающих спецификаций), факты, инструкции.

## Ограничения
- TypeScript: открытого негейтед-корпуса с лицензиями не найдено; в корпусе есть Python, JavaScript, Java, SQL;
  TypeScript представлен только синтетическими проверенными задачами.
- Токенизатор (словарь 8192) обучен на корпусе v1 и сохранён ради совместимости checkpoint; для кода и математики он
  менее эффективен, чем мог бы быть.
